## 2. 과정별로 채우는 것 (6개 블록 · 13개 값)

### ② 히어로 — `section.dhero`

| 자리 | 선택자 | 데이터 |

| 부처 로고 | `.dhero__gov img` | `주무관청` → `ministry-logo/{주무관청}-white@3x.png` |

| 소개문 | `.dhero__desc` | `자격증 소개(~란?)` |

### ④ 자격등록번호 — `.dreg__no`

`민간자격등록번호`. 안내 문구와 `민간자격 조회 바로가기` 버튼은 공통입니다.

### ⑦ 이런 분들에게 추천합니다 — `#who .dwho`

엑셀 `이런 분들에게 유용해요` 를 ` | ` 로 잘라 카드로 렌더링합니다. 번호는 `01.` 형태로 이미 붙어 있으니
`.dwho__no` 에는 순번만, `<p>` 에는 번호를 뗀 본문만 넣습니다.

항목 수는 과정마다 3~12개로 다릅니다. 캐러셀이라 가변이어도 되고, `.dwho__dots` 는 개수에 맞춰
자동 생성됩니다.

### ⑨ 진로 및 전망 — `.dintro--blue ul`

엑셀 `진로 및 전망` 을 ` | ` 로 잘라 `<li>`. `취업 길찾기` 링크는 공통입니다.

항목 수가 4~17개로 편차가 큽니다. 현재 디자인은 4~5개 기준이라 **상위 N개만 노출할지 결정 필요**
(8개 이상이 40건).

### ⑮ 커리큘럼 — `.dcurri`

`lecture_sessions` 의 `session_order` · `title`. 2열 배치이며 **왼쪽 열이 1~10강, 오른쪽 열이 11~20강**이

## 4. 반영 전 확인이 필요한 것

### 4-1. 자격등록번호 불일치

생활지원사 1급 기준 목업은 `2024-003062`, 엑셀·DB는 `2024-005425` 입니다.
`index.html` 본문과 `<meta name="description">` 두 곳에 들어 있습니다.

### 4-2. 교육 기간 6주 vs 4주

목업은 `신청일로부터 6주`, FAQ에도 "교육 기간 6주"로 두 번 나옵니다.
원본 사이트(kllo.kr)는 확인한 7개 과정 모두 `4주` 였습니다.
`courses.default_duration_days` 는 85개 전부 `NULL` 이라 판단 근거가 없습니다.

### 4-3. 교수 이력 데이터가 잘려 있음

전현영 교수 엑셀 값은 `[ 소속 ] 생활지원자 지도교수 한국직업능력검정협회 편집부 토브요양보호사 전임강사
[ 학력 및 전공 ]` 로, **`[ 학력 및 전공 ]` 뒤가 비어 있고 `생활지원자` 오타**가 있습니다.
목업의 3줄과 내용은 같습니다. 다른 과정도 같은 형태인지 일괄 점검이 필요합니다.

### 4-4. 이런 분들에게 유용해요 — 목업과 데이터가 다름

목업 03·04·06·07번과 엑셀 값이 다릅니다. 엑셀이 원본 사이트에서 받아온 최신값이므로
**엑셀 기준으로 교체**하면 됩니다.
